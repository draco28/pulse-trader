# Contributing

PulseTrader is a **solo-maintained, source-available, non-commercial** project
(see [LICENSE](LICENSE)).

- **External pull requests are not accepted** at this time. The repo uses an
  internal PR workflow for the maintainer's own changes.
- **Bug reports & feature ideas are welcome** — please open an issue.
- **Security issues:** do NOT open a public issue — see [SECURITY.md](SECURITY.md).
- By using this project you agree to the [LICENSE](LICENSE) (non-commercial)
  and the [DISCLAIMER](DISCLAIMER.md) (not financial advice).
